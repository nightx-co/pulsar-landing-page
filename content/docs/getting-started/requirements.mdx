Before using Pulsar, make sure your application runtime and PostgreSQL database meet the following requirements.

### Supported Runtimes

Pulsar supports the following JavaScript runtimes and execution environments:

For serverless environments, the runtime must provide enough CPU execution time for the Pulsar engine to initialize and perform its processing cycle. A **minimum CPU execution time of 2 seconds** is recommended.

<Callout title="Serverless Execution Limits" type="warn">
  Serverless platforms with shorter CPU execution limits may not provide enough execution time for Pulsar to operate reliably.
</Callout>

### Database Requirements

Pulsar requires a PostgreSQL database with the following extensions enabled:

* **pgmq** — Provides the underlying message queues.
* **pg_cron** — Enables scheduled queue processing and engine execution (must be version **> 1.6.4**).
* **pg_net** — Provides HTTP capabilities used by the processing engine.

Your database must satisfy all of these requirements before Pulsar can be initialized.
